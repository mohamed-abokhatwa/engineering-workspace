Download · r215 · updated 22 September 2026

Install it on your machine. Your documents never leave it.

The complete workspace — search, registers, the outbound check, the studios — installed on your own computer. Every install starts a 14-day full evaluation on your own documents; an activation code by e-mail continues it. Nothing here is uploaded anywhere, ever.

On Windows, the Microsoft Store is the simplest route and the one we would take: Microsoft signs and delivers the package, and it updates itself. The direct installer is there for the machines and the companies where the Store is not an option.

Windows

Installed and updated by the Store · Windows 10/11, 64-bit

The Store is the easiest way in: Microsoft signs and delivers the package, so there is no security warning to click past, and updates arrive by themselves. It is the same product, with the same 14-day evaluation.

Or the direct installer · 1.7 GB · for a company that blocks the Store, or an offline machine
Download the installer instead

Windows shows a SmartScreen notice for any installer it has not seen enough times yet, ours included — choose More info → Run anyway. The checksum below is there so you can confirm the file is exactly the one we published. The wizard checks your machine before installing and needs no internet during setup.

macOS

Installer package · 1.7 GB · Apple Silicon, macOS 13+
Download for Mac

A native installer wizard. On first launch, right-click the app and choose Open once — macOS asks this of any app it has not been told to trust yet. The checksum below confirms the file is exactly the one we published.

1 · Install
Everything ships inside the installer — both search-quality models, readers, the drawing converter, OCR. No downloads mid-setup, which is why the file is large.
2 · First run
A 15-second machine check, then your one-time setup code creates the admin account.
3 · Connect a folder
Point it at the project folders you already keep — indexed in place, nothing copied.
4 · Licence it
Type your activation code in Settings when the 14-day evaluation ends — until then the full product is yours to judge, with nothing to activate.
Verify your download

Two checksums, one command.

Every website installer is published with its SHA-256 checksum. Compare it with the file you downloaded — the two must match exactly. The Store package carries Microsoft’s signature and needs no manual check. The same values are in SHA256SUMS.txt and checksums.json.

What changed · r210 → r215

Since the last website release.

Updating while the app is openRun the installer while Engineering Workspace is open, or after closing its window while its server carries on in the background, and the installer now closes it for you before replacing the program — no restart of the computer. On Windows it says so on the page before it starts, and if another program is still holding one of its files it names that program and offers Try again. The Mac installer does the same.
Searchable while it is still readingA document can be found by its words the moment it is read, and search by meaning fills in behind it while you carry on — the folders you opened lately first, then contracts and specifications. Nothing is read twice: the same file kept in two places, a scanned page already read, a paragraph that has not changed are all taken on as they are. On Windows, scans are read by the reader built into Windows itself, English and Arabic together, and the reading of a set of documents can be packed up and carried to another computer.
Before you send, corrected and exportedThe full check shows what it is made of — four passes, each of which you can run alone — with a tick for every pass that has run on the draft as it stands. Correct the draft applies the report’s own recommended fixes and invents nothing: whatever only you know is left as a blank to fill in, and every change is shown word by word. Export writes the whole report, and the corrected draft, as a document on your letterhead.
Nothing you change in Settings is lostA setting changed and left without pressing Save used to be dropped in silence. Now one bar names every unsaved change, and a card saves itself when you move to another section or page — the daily report’s time included.
When Outlook asks for permissionClassic Outlook sometimes stops to ask whether a program may read the mailbox, and its dialog can open behind other windows. The Mail page now says when Outlook is waiting on you, can bring the dialog to the front, and tells you the answer that keeps it quiet; an opened message shows its text in the meantime instead of spinning.
An answer never comes back emptyWhen the assistant has nothing to show, it says why and what to do instead of leaving an empty reply, and an expired licence says so on the assistant as it does everywhere else. The time a long answer has taken keeps counting when you leave the page and come back.
Easier to read, page by pageOneNote pages are listed notebook by notebook and section by section, the way OneNote shows them. Search results say how well each one matches, in words, with the reason one hover away. Every page carries the same small How it works badge beside its name, with the page’s tour and its chapter of the manual behind it.
