Download · r220 · updated 25 September 2026

Install it on your machine. Your documents never leave it.

The complete workspace — search, registers, the outbound check, the studios — installed on your own computer. Every install starts a 14-day full evaluation on your own documents; an activation code by e-mail continues it. Nothing here is uploaded anywhere, ever.

On Windows, the Microsoft Store is the simplest route and the one we would take: Microsoft signs and delivers the package, and it updates itself. The direct installer is there for the machines and the companies where the Microsoft Store is not an option.

Windows

Installed and updated by the Microsoft Store · Windows 10/11, 64-bit

The Microsoft Store is the easiest way in: Microsoft signs and delivers the package, so there is no security warning to click past, and updates arrive by themselves. It is the same product, with the same 14-day evaluation.

Or the direct installer · 1.7 GB · for a company that blocks the Microsoft Store, or an offline machine
Download the installer instead

Windows shows a SmartScreen notice for any installer it has not seen enough times yet, ours included — choose More info → Run anyway. The checksum below is there so you can confirm the file is exactly the one we published. The wizard checks your machine before installing and needs no internet during setup.

macOS

Installer package · 1.8 GB · Apple Silicon, macOS 13+
Download for Mac

A native installer wizard. On first launch, right-click the app and choose Open once — macOS asks this of any app it has not been told to trust yet. The checksum below confirms the file is exactly the one we published.

1 · Install Everything ships inside the installer — both search-quality models, readers, the drawing converter, OCR. No downloads mid-setup, which is why the file is large.
2 · First run A 15-second machine check, then your one-time setup code creates the admin account.
3 · Connect a folder Point it at the project folders you already keep — indexed in place, nothing copied.
4 · Licence it Type your activation code in Settings when the 14-day evaluation ends — until then the full product is yours to judge, with nothing to activate.
Verify your download

Two checksums, one command.

Every website installer is published with its SHA-256 checksum. Compare it with the file you downloaded — the two must match exactly. The Microsoft Store package carries Microsoft’s signature and needs no manual check. The same values are in SHA256SUMS.txt and checksums.json.

What changed · r216 → r220

Since the last website release.

Presentations, made by the assistantAsk for a deck and the assistant makes it: a PowerPoint file with native charts you can still edit, speaker notes and headline figures, in the workspace’s own design or on your company’s template, with a PDF of the same slides; or the whole deck as one web page that plays in any browser. Arabic reads right to left, and the Daily report and the progress report export as slides too.
English and Arabic side by sideA deck can be bilingual: English on the left and Arabic on the right of every slide, block for block, with charts, tables and headline figures labelled in both languages and standard references left as written. Ask the assistant for one, or press Bilingual on any deck in Outputs, even one edited in PowerPoint since.
The PDF Studio’s page toolsArrange, split and insert pages, package drawings for a transmittal with a cover and a stamp, make a scan searchable, redact, crop, reduce, export pages as pictures, correct a run of text and sign. Every result is a new file, the original is untouched, and every output is checked in the engines people read PDFs with. Pages from office scanners now show in the studio.
A new lookDeep emerald and champagne gold by night, ivory by day, a serif for titles and figures, and the rooms numbered in the side bar. The same crest is now on the app icon, the installers and the Store tiles.
Search reads the whole deckThe library reads everything a PowerPoint holds, not only its text boxes: grouped shapes, tables, chart titles, categories and series, SmartArt and the speaker notes. It reads a web page without its style sheet or script. Decks and pages already in the library are read again once, by themselves.
Arabic, dated properlyIn Arabic, dates read naturally («29 أكتوبر 2026», where they used to come out as “Oct 2026 29”). The Dashboard’s lines and the assistant’s progress lines that stayed in English are translated.
Answers from your documents, even without AIWhen no AI account answers, the assistant and Ask show the passages of your documents that match the question as numbered cards, each with its document and page one click away. When an AI service sends back nothing, the answer says so plainly, and that nothing is wrong on your side. Indexing stays light on a computer with less than 32 GB of memory.
